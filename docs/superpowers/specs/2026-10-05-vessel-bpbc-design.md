# Vessel 基础 BPBC Java 复现设计

用户在 2026-10-05 批准直接开始。实现论文第 4.1–4.4 节和 EC.2，使用 Java 17、已安装的 COPT 8，独立编写代码。目标是可读、可运行的基础 BPBC，对应作者 BPBC_NONE 的范围；不宣称复现五项加速策略或论文的运行速度。

采用显式 best-bound 搜索树。每个节点：BMP 船舶列生成 → PBSP 引航员列生成 → 分离 Benders 割 → 重复至收敛；随后按泊位、任务时刻、任务班次、活动邻接顺序分支。定价继承节点的所有限制。

BMP 包含式 (38)–(41)。MPP 按船舶和泊位枚举可行进出时间，使用区间前缀和计算泊位资源对偶贡献。SPP 按 EC.2 进行前向标签、后向标签和休息连接；保留跨休息前后两任务的换岗时间条件。休息开始时间必须是 max(前任务结束, 休息最早开始)，不能在任务结束前休息。

PBSP 保留所有可行任务时刻的等式行。先在正需求网络定价，终止前在完整网络认证对偶可行性。非空路线的 μ≤1 可由覆盖等式与每个需求≤1推得，因此去掉冗余上界，使用 ζ=0 的式 (54)。若分支后的 PBSP 不可行，使用带正负松弛的 Phase I 和完整定价产生可行性割，不能用高罚值伪装为可行。BMP 同样用 Phase I 认证节点不可行。

求解达到 LP 最优且精确定价结束后才能使用节点下界。中途超时保留父节点下界，未找到整数解时明确报告。五项加速策略 DCG/LBL/VF/WS/PH 不在首版范围。

代码文件：Instance（数据和合法时刻）、Routes（列与割）、Restrictions（分支限制）、VesselPricing（船舶定价）、PilotPricing（引航员标签）、Master（BMP）、PilotProblem（PBSP）、Bpbc（节点迭代和搜索树）、Main（命令行）。COPT 调用限于模型文件和入口的环境生命周期；不引入 Maven、GUI 或框架。

验证包括：独立枚举与定价对比；小型完整 M2 LP 与根节点下界对比；独立枚举整数最优解与 BPBC 对比；四类分支与不可行节点；完整路线的对偶割检验；官方数据限时运行。合成实例标明合成，官方数据从作者仓库下载至被 Git 忽略的目录。只发布自己的代码、说明和真实测试结果，不上传许可证、求解器 JAR、论文 PDF 或作者源码。
